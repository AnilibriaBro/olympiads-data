# Данные для приложения «Олимпиады»

Перечень олимпиад школьников (РСОШ) и даты их этапов. Обновляется каждый день автоматически.

- `data/data.json` — файл, который скачивает приложение.
- Источники: [rsr-olymp.ru](https://rsr-olymp.ru/) (перечень и уровни), [olimpiada.ru](https://olimpiada.ru/) (даты этапов).
- Обновление: `.github/workflows/update-data.yml`, каждый день в 04:00 по Москве. Запустить вручную: вкладка Actions → «Обновление данных» → Run workflow.
- Локально: `python scripts/update_all.py`.
